## 2026-11-22 · 분해 설계 v1

- 순위는 Astra, 상태·검증·되돌림은 Python과 공식 ASAP이 관리한다. 최종 두 부품의 native 규칙도 기록한다.
- 후보의 허용 자세 전체 실패와 개별 검사를 구분한다. 원래 목표가 같은 시작 노드에서 이어진 채택 경로로 제거돼야 장기 저장 자격을 얻는다.
- 조회할 기억은 실행 시작에 고정한다. 실패 검사 단계와 결과가 같은 사례에서 실제 PNG의 DINOv2 임베딩으로 최대 3건을 찾는다. 모의 응답 사례는 분리된 DB를 사용한다.
- 기본 단위는 시뮬레이터 cm로 통일하고 입력 단위·변환을 남긴다. 지지·물리 기준은 upstream과 동일하게 적용했다. 수치 기하만으로 제작 의도나 체결 상태를 추론하지 않는다.
- 추후 확인할 것은 자유로운 실제 Astra의 해결지침 생성·인용·재사용과 미지 제품에서의 유용성이다. [근거와 실행 예산](../reports/MASTER_DESIGN_DELIVERY_20261122.md)
